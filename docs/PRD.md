# PaperPrism — 论文文献对比 Agent 需求文档（PRD）

> 版本：v1.0　日期：2026-10-23　状态：已确认，进入开发

---

## 1. 产品概述

### 1.1 一句话定位
PaperPrism 是一个**本地优先**的论文文献对比 Agent：把多篇论文"折射"成一张可溯源的结构化对比矩阵、一份对比分析报告和一个可追问的多论文问答助手，支持自由配置和切换任意大模型 API，界面采用类 Apple 的磨砂玻璃悬浮风格。

### 1.2 背景与痛点
| 痛点 | 现状 |
|---|---|
| 读多篇论文后横向对比困难 | 手工建 Excel，逐篇翻找方法、数据集、指标，耗时且易遗漏 |
| AI 总结不可信 | 通用聊天工具给出的结论无页码、无原文，无法核对 |
| 商业工具贵且封闭 | Elicit / SciSpace 月费 $12–79，抽取维度无法自定义，数据在云端 |
| 模型绑定 | 多数工具只支持单一厂商，无法用国内模型、中转服务或本地模型 |

### 1.3 产品目标
1. 5 分钟内完成 "导入 3 篇论文 → 得到对比矩阵"。
2. 矩阵中 ≥90% 的单元格附带原文引用与页码。
3. 支持 OpenAI 兼容 / Anthropic / Ollama 三类接口，切换模型无需重启。
4. 视觉达到"像 macOS 原生应用"的精致度。

### 1.4 目标用户
- **研究生 / 博士生**：开题、写综述、Related Work。
- **科研人员 / 工程师**：技术选型、跟踪 SOTA。
- **审稿人 / 导师**：快速横向评估一组稿件。

### 1.5 产品形态
- **一期**：本地 Web 应用（`npm run dev` / `npm start`，浏览器打开 `localhost:3000`），单用户、无登录，数据存本地。
- **二期**：Tauri 打包为 macOS / Windows 桌面应用，使用系统原生 vibrancy 材质。

## 2. 竞品与开源调研

| 项目 | 类型 | 核心能力 | PaperPrism 借鉴 / 差异 |
|---|---|---|---|
| **Elicit** | 商业 SaaS | 检索论文并抽取为表格 | 借鉴"论文×维度"表格；差异：维度完全可自定义、本地、免费、可换模型 |
| **SciSpace** | 商业 SaaS | 搜索、PDF 对话、文献表 | 差异：更深的结构化对比与可视化 |
| **LitPilot** (GitHub) | 开源脚本 | PDF→结构化笔记+Excel+跨论文综合 | 借鉴**证据溯源**：每条结论绑定页码、原文引用、"作者陈述/模型推断"标签 |
| **PaperQA2** | 开源 | 科学 PDF 的 RAG 问答，精确引用 | 借鉴多论文问答 + 段落级引用 |
| **UNU Agentic Paper Review** | 开源 | Specialist/Editor/Judge 多角色、多模型对比+裁判、Token 计费 | 借鉴多模型交叉抽取、差异仲裁、成本统计 |
| **Paper Circle** (arXiv 2604.06170) | 开源 | 发现管线+分析管线，JSON/CSV/BibTeX/MD 输出 | 借鉴管线化设计与多格式导出 |
| **STORM** (Stanford) | 开源 | 先大纲后成文的长文生成 | 借鉴报告 Agent 的 Plan→Draft→Review |
| **GPT Researcher** | 开源 | Plan→Search→Read→Reflect→Synthesize | 借鉴 Agent 步骤可视化 |
| **ChatPaper** | 开源 | arXiv 抓取+总结 | 借鉴 arXiv 导入 |
| **Cherry Studio / LobeChat** | 开源客户端 | 多 Provider 配置、连通检测、拉取模型列表 | 借鉴 API 配置中心交互 |
| **liquid-glass-html-css / liquidGL / kevinbism/liquid-glass-effect** | 开源 UI | `backdrop-filter`、多层 inset 高光、SVG 位移折射 | 借鉴玻璃材质实现与降级策略 |

**结论**：开源社区尚无"本地 + 可换模型 + 可溯源对比矩阵 + 报告 + 问答 + 可视化"一体化且注重视觉体验的产品，这是 PaperPrism 的切入点。

## 3. 功能需求

优先级：**P0** = 一期必做；**P1** = 一期尽量做；**P2** = 二期。

### 3.1 API 配置中心（Providers）
| ID | 功能 | 说明 | 优先级 |
|---|---|---|---|
| A-1 | 新增/编辑/删除 Provider | 字段：名称、类型（OpenAI 兼容 / Anthropic / Ollama）、Base URL、API Key、是否启用 | P0 |
| A-2 | 预设模板 | 一键填入 OpenAI、DeepSeek、通义千问(百炼)、Kimi、智谱、硅基流动、OpenRouter、Anthropic、Ollama 的默认 Base URL | P0 |
| A-3 | 连通性测试 | 发一次极短请求，返回耗时或错误信息 | P0 |
| A-4 | 模型管理 | 自动拉取 `/models` 列表，或手动添加模型 ID；单个模型可启用/禁用 | P0 |
| A-5 | 全局模型切换 | 顶部胶囊栏下拉框，任何页面随时切换当前模型 | P0 |
| A-6 | 按任务指定模型 | 抽取 / 报告 / 问答各自可指定模型（默认跟随全局） | P1 |
| A-7 | Key 加密存储 | AES-256-GCM 加密存于本地 SQLite，界面只显示掩码 | P0 |
| A-8 | 参数 | temperature、最大输出 token、并发数 | P1 |
| A-9 | 用量统计 | 按模型统计请求数、输入/输出 Token，可选填单价估算费用 | P1 |

## 6. 视觉设计规范（Glass Design System）

### 6.1 设计原则
- **悬浮**：所有内容容器是浮在动态背景之上的玻璃层，带柔和大投影。
- **通透**：背景色彩透过玻璃被模糊、提亮饱和度。
- **克制**：色彩主要来自背景，前景以中性色 + 单一强调色（系统蓝 `#0A84FF`）为主。
- **层级**：玻璃有 3 级厚度（thin / regular / thick），越上层越不透明。

### 6.2 材质 Token
| Token | 浅色 | 深色 |
|---|---|---|
| `--glass-bg` | `rgba(255,255,255,0.55)` × 强度系数 | `rgba(28,28,32,0.55)` × 强度系数 |
| `--glass-blur` | 28px（thin 16 / thick 40） | 同左 |
| `--glass-saturate` | 180% | 160% |
| `--glass-border` | `rgba(255,255,255,0.6)` | `rgba(255,255,255,0.12)` |
| `--glass-highlight` | `inset 0 1px 0 rgba(255,255,255,0.7)` | `inset 0 1px 0 rgba(255,255,255,0.15)` |
| `--glass-shadow` | `0 20px 60px -12px rgba(30,40,80,0.25)` | `0 20px 60px -12px rgba(0,0,0,0.6)` |
| 圆角 | 卡片 24px、按钮 12px / 胶囊 999px、侧栏 28px | |

### 6.3 背景
- 3–4 个大尺寸彩色光斑（蓝、紫、粉、青），`filter: blur(80px)`，20–40s 缓慢漂移动画。
- 浅色：光斑在 `#F2F4F8` 底上；深色：光斑降饱和，底色 `#0B0C10`。
- 叠加极淡的噪点纹理，增加真实玻璃质感。

### 6.4 组件
GlassPanel、GlassCard、GlassButton（primary/secondary/ghost）、GlassInput/Textarea/Select、SegmentedControl（滑块动画）、Switch（iOS 风格）、Slider、Modal/Sheet（弹簧缩放进入）、Drawer、Toast、Tooltip、Badge、Progress（流光）、Skeleton（玻璃微光）、CommandPalette（⌘K）。

### 6.5 动效
- 弹簧曲线（stiffness 300–400, damping 30）作用于弹窗、分段控件滑块、卡片 hover 上浮。
- 卡片 hover：鼠标位置跟随的径向高光（spotlight）。
- Agent 运行中：面板边框流光（conic-gradient 旋转）。
- 遵守 `prefers-reduced-motion` 与设置项。

### 6.6 字体
`-apple-system, "SF Pro Text", "PingFang SC", Inter, "Helvetica Neue", sans-serif`；数字使用等宽数字 `font-variant-numeric: tabular-nums`。

### 6.7 无障碍与降级
- 文字与玻璃背景对比度 ≥ 4.5:1（玻璃底色保底不透明度）。
- "减少透明度"开启时：关闭 blur，玻璃变为 96% 不透明实色。
- 不支持 `backdrop-filter` 的浏览器自动降级为半透明实色。

## 9. 风险与对策
| 风险 | 对策 |
|---|---|
| 扫描版 PDF 无文本 | 一期检测并提示"无文本层"，支持粘贴文本补救；二期 OCR |
| 公式/表格抽取不准 | 纯文本抽取 + Prompt 要求只引用原文；后续可选接 MinerU API |
| 小模型不支持 JSON 结构化输出 | 采用"JSON in text"+ Zod 校验 + 修复重试，不依赖 tool calling |
| 论文超出上下文 | 按章节优先级截断 + 每维度检索相关片段（BM25） |
| 部分浏览器玻璃效果差 | 分级降级，保证可读性 |
